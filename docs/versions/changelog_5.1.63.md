# 5.1.63

- 优化 X 普通同步：每批最多读取 3 页，遇到已同步边界停止，未完成时保存游标继续，不再反复从第一页扫描。
- 历史补全独立分批执行，重新扫描移至需要确认的“修复同步”操作。
- 收藏同步与 AI 整理分离，收藏先保存，AI 每批最多整理 20 条，单条限时 90 秒。
- AI 结果逐条保存并更新进度；失败不阻塞整批，后续批次继续处理待整理内容。
- 防止 AI 整理期间同步更新的收藏被旧结果覆盖。
- 回到前台时补查可执行任务及遗漏的重试调度。
- 任务进度区分已读取页数、本批上限和收藏条数，展示 AI 整理成功与失败数量。

说明：后台任务实际开始时间仍受 Android 系统调度和网络条件影响。
