4. 附件与入库

知识库不是黑盒，保存前给出将要生成的来源、关联和标签建议。

相比上一版的细节变化

  1. 去掉大面积装饰背景，页面更沉稳，更接近日常工具。
  2. 首页采集区从分散按钮改成单一面板，录音主动作和辅助动作关系更清楚。
  3. 卡片增加左侧状态线，比彩色大块更克制，也更容易扫读。
  4. 底部导航降低视觉权重，避免和采集入口竞争。

我建议定稿的产品取舍

  • 录音按钮一点即开始，权限弹窗是唯一阻断。
  • 实时转写可配置，但 UI 默认支持“先录后转”。
  • 视频先做附件和备注，不做视频内容识别。
  • 文件先入库并排队解析，解析失败不影响日记保存。
