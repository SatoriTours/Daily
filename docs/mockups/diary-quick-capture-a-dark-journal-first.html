4. 保存的是一篇日记

知识库入库变成保存后的后台能力，不把用户带到管理型流程里。

新的交互原则

  1. 点击录音立即创建一篇日记草稿，获得真实 `diary_id`。
  2. 后台录音、转写、附件都绑定这篇日记，不再创建独立“录音项目”。
  3. 日记列表只按时间组织，不出现“全部/录音/待整理/已入库”筛选。
  4. 知识库处理是保存后的异步能力，状态可在日记卡片上轻量提示。

实现含义

  • `startRecording` 先插入 diary 草稿，再启动前台录音服务。
  • 录音文件、转写结果、视频、文件都作为 diary attachment 关联。
  • 转写完成后用户确认是否合并正文，再触发 memory extract。
  • 删除这篇日记时，关联附件和对应 memory/source 引用一起清理。
