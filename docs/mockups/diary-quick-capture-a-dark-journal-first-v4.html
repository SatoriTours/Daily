3. 录音中才占一点空间

只有录音进行中才出现迷你录音条，平时不压缩日记列表。

这版的核心修正

  1. 去掉常驻“写点什么”输入框。
  2. 新增入口缩成右下角 42px 小悬浮按钮。
  3. 点开后显示四个动作：语音日记、文字日记、拍摄、文件。
  4. 录音中才显示底部迷你录音条。

产品逻辑不变

  • 点“语音日记”立即创建一篇日记。
  • 录音、转写、附件都绑定这篇日记。
  • 后台录音仍然通过前台服务和通知栏保持可见。
  • 保存后异步加入知识库。
