方案 03 · 内容切换对比
A 推荐 · 紧凑双段控件
B 备选 · 单一模式菜单

推荐 A：小型双段切换。

去掉通栏底线和蓝色下划线，用一组低对比控件表达同一篇文章的两种读法，不再像又增加了一层导航。

A / 两种读法都看得见

始终看到摘要与正文，一次点击切换；选中态用柔和底色承托。控件仅宽 148，不占满整行，视觉高 32、可点区域高 44。

B / 更安静，但多一步

只显示当前模式「摘要⌄」，展开菜单后切换正文。更克制，但入口不如 A 直观，也需要两次操作；只有两种模式时不优先推荐。
