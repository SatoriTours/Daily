处理记录 · 双向关联 v4

短信中直接看到对应账目与待办的实际信息，点击进入详情；账目与待办详情都能查看原文，并定位回这条来源记录。
可点击关联条目和「查看来源记录」体验双向导航；补建按钮保持右对齐。以下数据均为设计示例，不执行真实业务操作。

A · 短信 → 关联结果显示内容，不只是数量

账目显示商户、金额与状态；待办显示标题、时间与状态。
每个关联条目都可进入其详情，多条结果逐条展示。

B · 账目 → 来源短信浅色 / 同一条来源

来源信息直接展示短信预览，点击定位对应处理记录。
同一账目有多个来源时逐条列出，不只保留一个。

C · 待办 → 来源短信深色 / 同一条来源

原文与识别出的待办分开呈现，方便核对。
原文清除后显示「原文已清除」，不影响已生成的结果。
