DAILY SATORI · 日记列表

让第一行标题，在收起时也一目了然

标题独立一行加粗，正文从下一行开始；沿用当前列表的时间、标签和展开入口。

01 当前 · 收起

标题与正文合并成三行纯文本，扫列表时很难直接找到主题。

02 方案 · 收起 推荐

标题 17sp 加粗，最多两行；正文单独预览三行。点击「展开正文」体验。

03 方案 · 展开

展开继续按 Markdown 渲染完整原文，标题只出现一次。

只识别首行一级标题

首行写成 # 标题 时提取标题，并从正文预览中移除这一行。普通首行、## 和 #标签 保持现有预览。

长标题和仅有标题

长标题最多两行后省略，展开可看全文；只有标题时，只展示标题，不出现空正文或无意义的展开按钮。

用排版建立层级

标题用主题正文色加粗，正文沿用当前样式，时间与心情保持弱色。浅色与深色均可预览。
