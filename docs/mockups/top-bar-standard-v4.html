日记一键记录，标题栏回归简洁

完整交互设计 V4 · 默认侧边收纳，点击横向展开，不占固定行。六个日记场景 + 四类全局模板。内容为示例；不实际录音、不调用 AI、不写入 App。

所有页面共用的规则

01 · 顶栏最多两个操作位

页面操作 + AI，AI 永远最右。多项操作用“更多”；只有设置一项就直接显示齿轮，不再套一层菜单。

02 · 高频记录不隐藏

默认仅露约 14dp 的侧边手柄，实际触区 48dp。点击先展开，不会直接启动录音；展开后“＋ / 录音”横排，视觉各 36dp。

03 · 真悬浮，不占一行

侧边手柄、展开按钮与录音条均悬浮，列表延伸至导航上沿。只给末尾加可滚动留白，让最后一条能滚到浮层上方读完。

04 · 状态就地替换

点击列表空白或滚动可收回，不设自动消失倒计时。录音中状态条常显，不因点击空白或滚动而隐藏；完成后回到侧边手柄。

05 · 编辑与搜索使用专用模板

编辑保留直接保存；搜索用返回、输入框、AI。附件、标签、心情和“收为点子”属于编辑任务工具，不挤进顶栏。

06 · 不机械复制日记布局

今日不新增悬浮按钮；读书保留已有“记感想”；我的直接设置。最小触区 48dp，窄屏和大字不靠缩字硬塞。

本页 CSS px 只是设计比例，不等同 Android dp。示例录音时长与转写为模拟。浏览器预览不代表 Android 键盘、录音权限、触控或 App 运行验收。
