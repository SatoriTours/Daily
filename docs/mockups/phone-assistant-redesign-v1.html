改动点

  • ① 删「信息接入」大标题与说明，两个频道压成 52px 状态条：圆点颜色表示状态（绿＝已接通、橙＝需处理、灰＝未开启），整条可点进配置。
  • ② 三层 tab 改 下划线式并吸顶：计数做成徽标，滚动时始终可见。
  • ③ 待办改 按 今天／本周／更晚 分组的行式列表，右侧一个完成圆钮，不再每条都套大卡。
  • ④ 账目把 粒度切换与期次导航并成一行；合计从「锚点月」改为 整段区间小计（近 7 天／6 周／6 个月），与分桶不再重复。
  • ⑤ 分桶头与条目拆成「日期行 + 条目行」，条目只留金额、商户、来源时间，点行进入编辑。
  • ⑥ 常驻底部隐私说明移到设置页顶部，首屏多出约 60px。

对比（首屏可用高度 844px）

  • 现在：顶栏 98 + 信息接入块 500 + tab 62 + 内容区 ≈ 180 → 列表只露一行。
  • 改后：顶栏 98 + 状态条 60 + tab 44 + 内容区 ≈ 640 → 待办可见 5 行、账目可见 3 个分桶。
  • 空态卡同时瘦身：图标 44px 无容器、文案两行封顶、保留主按钮。
  • 配色与间距全部沿用现有主题（背景 #F5F5F7、卡片 #FFFFFF、主色 #006EDB、圆角 14/18/22、间距 8/16）。
