# 全局标题栏与页面操作规范（V4 已确认，代码级验收通过）

## 目标

从“我的日记”五个并列按钮的问题出发，统一全 App 的页面操作层级。减少的是竞争注意力的入口，不删功能、不缩小点击区域、不把高频记录藏进菜单。保留已经确认的最右侧全局 AI 入口。

## 标题栏规则

1. 普通浏览页右侧最多两个操作位：**页面操作 + AI**，AI 固定最右。页面有多项操作时用“更多”，只有一项时直接展示（如“我的”的设置）。返回/关闭在左侧，不计入右侧预算。
2. 两个是上限，不是必须填满；没有页面操作时仅保留 AI。同一功能不在同屏重复放入口，不强迫每页都有悬浮按钮。
3. 编辑态右侧为“保存 + AI”；保存不能收进菜单。搜索态用“返回/退出搜索 + 搜索字段 + AI”，不叠加普通态图标。
4. 次要操作用有文字标签的“更多”菜单承载，如筛选、排序、标签管理、分享；删除须保留二次确认。筛选生效后才显示可清除的条件条，默认不增加一排常驻工具。
5. 日记的添加/录音采用右侧收纳入口：默认只露出小手柄，点击后横向展开两枚独立按钮，展开后各一键执行。不收入顶部更多，不合成分段胶囊；接受默认状态先展开、再执行的两步操作。其他页不照抄日记的双按钮。
6. 窄屏/大字体仍保留两个操作位和至少 48dp 热区，不靠缩字塞按钮。长内容标题在正文完整呈现，顶栏承担简短定位；菜单宽度和行高适配大字与窄屏。
7. 图标、颜色、字体、圆角沿用主题。普通图标用次要文字色，AI 沿用现有强调色；不再增加第二种高饱和色。点击热区至少 48dp。
8. 标题栏固定在滚动区外。正文中不重复堆叠同一页名、同一操作和常驻说明。

## 页面模板

| 场景 | 左侧 | 右侧（从左到右） | 页面主要操作 |
|---|---|---|---|
| 我的日记 | 我的日记 | 更多、AI | 右侧手柄默认收纳，点击横向展开“＋ / 录音”；均在底部导航上方 |
| 今日 / 读书等列表 | 页面名 | 更多（多项时）或唯一页面操作、AI | 今日不凭空新增按钮；读书保留既有“记感想”，添加书籍仍在既有菜单 |
| 我的 | 我的 | 设置、AI | 保留原功能列表，不加无意义的更多菜单 |
| 文章等详情 | 返回、简短定位标题 | 更多、AI | 阅读内容；收藏/分享等原功能在更多中，长标题在正文完整呈现 |
| 编辑 | 关闭/返回、编辑标题 | 保存、AI；没有其他操作不加更多 | 编辑器；关闭保留既有草稿/未保存提示 |
| 搜索态 | 返回/退出搜索、搜索字段 | AI | 搜索结果；不再保留一排普通态图标 |
| 助手自身 / 确认弹窗 / 行内工具 | 沿用所属任务导航 | 不重复全局 AI；不机械套普通页模板 | 任务内操作 |

## 日记页细化

- 顶栏从五个入口减为“更多 + AI”。更多包含“搜索日记”“标签筛选”“标签管理”，不收录新建和录音。
- 默认仅在右侧露出约 14dp 宽的小手柄。视觉半藏在屏外，但透明的 48×48dp 实际触区完整留在屏内；点击只展开，不直接启动录音。
- 点击向左横向展开“＋ / 录音”，不再竖排；两枚按钮视觉均为 36dp、图标约 19–20dp，热区各 48dp、互不重叠。录音用强调色，添加用中性表面色，不做分段胶囊。
- 点击列表空白或开始滚动可收回，不设自动消失倒计时；点击正文仍直接进入原本的查看/编辑流程，不吞掉第一次点击。浏览器提供 Escape 收起并把焦点还给手柄。
- 手柄、展开按钮与录音条直接浮在列表之上、底部导航上方，不参与高度分配、不预留单独一行、不加固定底栏背景。列表末尾仅加可滚动余量（设计比例 88dp），让最后一条能滚到浮层上方完整阅读。
- 录音中显示已认可的悬浮状态条，保留暂停/继续/完成及 48dp 控件热区；点击空白或滚动不隐藏正在录音的指示。完成后回到默认收纳状态，转写继续归记录与现有任务；收纳不取消任务或清空草稿。
- Starting/Stopping 阶段防止重复触发；失败/落盘失败复用原错误与恢复流程。完成录音先确认本地落盘，转写状态归记录/现有任务，不以已提交冒充转写成功，不把后台转写当成一直在录音。
- 编辑稿仅规范顶栏与工具层级，保持既有编辑抽屉、附件、心情、标签和“收为点子”等能力；次要编辑操作放任务内工具区，不占第三个顶栏操作位。
- 已选标签沿用可清除条件条，搜索沿用现有查询与退出行为；不改数据、权限、转写或任务生命周期。

## 工程落地与验收边界

- 确认后将本规范纳入 `docs/04-style-guide.md`，由共享顶栏统一处理右侧预算/溢出，页面提供有名称、优先级和行为的操作，不再无约束地追加图标。
- 日记先落地，随后按同一清单检查普通列表、详情、自定义顶栏、搜索/编辑模式，防止少数页面绕过共享规则。
