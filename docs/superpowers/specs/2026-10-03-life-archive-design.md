# 生活档案与可逆脱敏设计

## 目标与已确认流程

用户需要长期保存域名、订阅、海外付款方式等资料，不逐项填写表单。用户已确认采用「本地脱敏 → 上传内容预览 → 云端 AI 整理 → 本地还原 → 确认保存」。本规格细化工程边界，尚未获用户对书面规格的确认。

成功标准：粘贴一段文字即可生成一条或多条资料草稿；确认过的敏感片段不进入网络请求；异常返回不会被直接还原并保存；最终资料保持本地私有。

## 第一版范围

- 在「我的」页面增加「生活档案」入口，独立列表、搜索、详情及编辑/删除。
- 新增时输入或粘贴文字；支持域名、订阅、支付方式、其他四个分类。一段文字可生成多条草稿，逐条确认保存。
- 每条资料包含随机 ID、标题、分类、正文、键值属性及创建/更新时间。缺失内容留空，不生成未提供的账号、金额、日期等事实。
- 允许用户直接编辑资料；脱敏只发生在云端整理之前。
- 第一版仅支持文字，不接入截图 OCR、语音识别、自动抓取账号、提醒关联、跨资料自动关联或云端同步。
- 第一版不导入完整银行卡号、密码、CVV 或恢复码作为资料；付款资料使用名称、尾号和用途。相关内容在上传预览中提示删除，不能因为已有占位符而放行。

## 交互与状态所有权

ViewModel 是一次整理会话的唯一所有者，状态依次为输入、脱敏预览、等待请求、草稿确认和完成。

1. 在本地识别邮箱、域名/URL、电话号码、银行卡/较长数字串，以及账号/姓名/地址/订单号等标签后的值；同值在同一请求中使用同一占位符。
2. 展示完整的实际上传文本、匹配片段数量和所用 AI 配置。明确提示姓名、自由文本地址等可能漏识别，剩余语义仍会上传；不能显示「已完全匿名」等保证。
3. 用户可以选择任意文字片段补充遮盖或撤销某处遮盖。上传预览修改后重新生成会话及映射；用户再次点击发送才发起请求。
4. 输入为空、超过 20,000 字、存在尚未处理的禁止凭据或占位符语法冲突时阻止发送。
5. 请求返回并通过校验后，在本地还原草稿。用户确认后才写入档案；取消不保存。

输入改变、切换配置、取消、离开页面均使旧请求失效。取消协程并通过会话 ID 丢弃迟到结果；等待期间禁止重复发送。修改原文必须重新确认上传预览。原文、映射、响应及未保存草稿只驻留内存，不进入 SavedStateHandle 或后台任务持久化；进程结束需重新输入。

## 可逆脱敏与返回协议

共享模块实现纯逻辑的脱敏会话与草稿编解码，便于代码级测试。

- 使用每次会话随机命名空间和类型化占位符，例如 `__PRIVATE_<session>_EMAIL_1__`。会话间不复用标识，不以真实值计算可追踪的哈希。
- 按原文区间替换；邮箱、URL 等较完整匹配优先，重叠区间只替换一次。补充遮盖可覆盖整句；原文中的类似占位符文本需先处理，避免冲突。
- 映射包含原值、类型和本会话占位符，只留在本地内存。发送接口只能接受脱敏请求对象，不能接收原文或映射。
- AI 输入仅包含固定整理指令和用户已确认的脱敏文本；不附带聊天历史、记忆、工具或其他资料。
- 要求返回严格 JSON：`records` 数组，每条含 `title`、`category`、`body`、`fields`；属性值为字符串。限制最多 20 条、返回文本最多 100,000 字；拒绝未知分类、无有效条目或不符合结构的响应。
- 占位符必须原样保留在字符串值中，不允许作为 JSON 键。先解析和验证结构，再替换字符串值，不能在原始 JSON 上直接做字符串替换。
- 校验所有占位符属于当前会话、类型与明确的属性类型相符。无法判定的普通正文仍需用户检查；不声称能自动证明占位符没有被移到错误语境。
- 任一占位符缺失、变形、未知或类型冲突均拒绝整个返回，不自动保存、不将原文用于补救请求。允许用户重新发送同一脱敏预览。
- 一次替换扫描只还原当前返回文本中的占位符，不递归扫描还原后的原值。

## AI 边界与错误处理

复用默认 AI 配置、已有网络协议和 DI 模式，新增独立的生活档案整理服务，不接入 MCP Agent 或 MemoryExtractService。

现有 `AiService` 会记录异常，错误响应正文可能随异常进入诊断。实现时应沿用底层协议，但为本功能提供不记录请求/响应正文及远端错误正文的调用边界；仅保留固定错误类别、HTTP 状态等非内容诊断，不扩大修改其他 AI 功能。

仅将已确认的脱敏文本发送一次；不自动回退到原文，不因校验失败自动调用其他模型。错误信息使用固定中文提示，禁止回显远端异常正文。收到取消必须继续传播取消异常。没有有效 AI 配置时指向配置页面，保留本次输入于当前页面内存。

## 本地存储与隔离

为避免现有数据库、记忆重建和数据库备份携带档案，第一版使用独立的 Android 私有文件仓库，位于 `noBackupFilesDir/life_archive/`，不修改 `DailySatori.sq`，不新增数据库迁移。

- 复用 `SecretValueCipher` / Android Keystore AES-GCM；将每条完整 JSON 作为一个加密值保存，标题、分类、属性和正文均不以明文落盘。文件名只含随机 ID。
- 现有 `SecretCipher.decrypt` 失败时会返回密文，仓库需检查返回值确实是可解析且 ID 匹配的资料；失败必须报错，不展示空列表冒充成功，不覆盖原文件。
- 写入使用同目录加密临时文件和原子替换；串行执行写入/删除，状态更新只发生在成功落盘后。列表搜索在解密后的内存数据中执行。
- Android 实现注入共享仓库接口；Koin 注入 ViewModel，不在 Composable 中访问文件。只支持当前 Android 产品，不为其他平台增加假实现。
- 不纳入现有备份目录收集、数据库导出、全文检索、记忆提取、聊天上下文或任务中心内容。现有 Manifest 已关闭 Android 自动备份。
- 本次不触碰用户正在修改的 `Config.kt`、`BackupService.kt` 及其测试。

**第一版取舍：档案不支持迁移到新设备；卸载/清除数据、Keystore 密钥丢失均可能使档案无法恢复。** 页面需在首次保存前清晰显示此限制，不把仅存在本机的数据描述为已备份。加密导出/恢复属于后续单独设计，不默认为现有备份可以恢复档案。

## 拟修改位置

- `shared/.../service/lifearchive/`：数据模型、脱敏与还原、严格响应解析、专用 AI 整理边界及仓库接口。
- `app/.../core/lifearchive/`：加密文件仓库。
- `app/.../ui/feature/lifearchive/`：列表/编辑流程与 ViewModel。
- 现有 `MySpaceScreen`、`HomeScreen`、导航 Routes/NavHost、Koin 模块及中英文字符串：接入入口与页面，复用主题样式。
- `docs/03-app-features.md`：实现后补充功能及私有边界说明。

## 验证与验收

先写最小聚焦测试并确认失败，再实现并运行同一测试。聚焦覆盖：重复与重叠敏感片段、补充遮盖、跨请求标识隔离、特殊字符还原、恶意/缺失/变形占位符、原值含占位符时不递归、严格 JSON、空/超限响应、迟到响应丢弃。

使用假传输捕获实际请求，断言原文敏感值和映射不在请求体中；失败及重试也保持这一条件。使用假加密/文件存储验证落盘不含明文、写入失败保留原档案、损坏/密钥丢失不覆盖数据；Android 编译确认 Keystore 和私有目录接入。

功能结束时合并一次运行受影响模块代码级测试、`:app:compileDebugKotlin` 与 `:app:assembleDebug`（涉及字符串资源），不启动模拟器、不执行 UI 测试、不实际上传用户资料。

安全验收只保证匹配到且已遮盖的片段不会发送；规则漏识别和剩余语义关联风险必须在预览中如实呈现。真实云端模型效果、设备存储行为和 UI 操作仍需后续专项验证，不以代码级测试声称已完成真机验证。
