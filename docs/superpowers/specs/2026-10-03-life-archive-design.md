# 生活档案与 AI 整理设计

## 目标与已确认流程

用户需要长期保存域名、订阅、海外付款方式等资料，不逐项填写表单。按已确认的界面和最新要求，新增采用「输入文字 → 云端 AI 整理 → 确认保存」，编辑采用「现有资料 + 新的文字说明 → 云端 AI 优化 → 确认保存」。取消脱敏、占位符替换、上传预览及本地还原流程。原始输入，以及编辑时的当前资料和补充说明，会发送给用户所选 AI 服务。另支持 AI 分析现有待办，把续费、订阅类信息导入档案。

成功标准：粘贴一段文字即可生成一条或多条资料草稿；已保存资料可通过新的文字说明补充、纠正和整理；AI 不编造字段值，不直接覆盖已保存资料；用户确认的资料在本地加密保存。

## 第一版范围

- 在「我的」页面增加「生活档案」入口，独立列表、搜索、详情及编辑/删除。列表默认只显示右上角搜索图标，点击后展开搜索框，关闭后清空搜索并收起。
- 新增时输入或粘贴文字；预置域名、订阅、支付方式、其他分类，支持「＋类型」新增自定义类型、长按重命名及删除。分类使用稳定 ID，重命名不影响资料；删除有资料的类型时先要求选择另一个类型迁移，不删除资料。
- 一段文字可生成多条草稿，逐条确认保存。每条资料包含随机 ID、标题、分类 ID、正文、有序键值属性及创建/更新时间。
- 字段名由 AI 按类型和内容生成，常见类型提供字段名称参考，自定义类型按内容整理。同类型只参考已有字段名，不携带其他资料的值；每条资料可有不同字段。缺失内容留空或省略，不生成未提供的账号、金额、日期等事实。
- 支持手动修改字段名、值、正文和分类，以及增删字段；编辑页增加文字输入区和「让 AI 优化」动作，例如「付款卡改成尾号5678，补充每年8月续费」。
- 第一版仅支持文字，不接入截图 OCR、语音识别、自动抓取账号、提醒关联、跨资料自动关联或云端同步。

## 交互与状态所有权

ViewModel 是一次整理会话的唯一所有者，状态依次为输入/编辑、等待请求、草稿确认和完成。

1. 新增时，输入或粘贴文字，点击「AI 整理」发起请求；输入为空或超过 20,000 字时阻止发送。
2. 编辑时，在当前资料下输入新的说明，点击「让 AI 优化」，将当前编辑草稿和说明一起发送。资料 ID 与创建时间只在本地维护。
3. 编辑提示词要求保留未涉及的信息：明确纠正的值替换旧值，新增信息补充；删除字段必须有明确指令。涉及不同字段的模糊指令不能猜测应删除哪些信息，需在草稿中提示用户确认。
4. 返回通过结构校验后展示可编辑草稿。编辑结果标记新增、修改和删除的字段，并保留修改前版本以支持放弃本次优化。
5. 用户点击「确认保存」才落盘；返回失败、取消、放弃优化都不改变已保存资料。重复优化以当前待确认草稿为输入；取消当前优化恢复到本次请求前的草稿。

输入改变、切换配置、取消、离开页面均使旧请求失效。取消协程并通过会话 ID 丢弃迟到结果；等待期间禁止重复发送。原文、响应及未保存草稿只驻留内存，不进入 SavedStateHandle 或后台任务持久化；进程结束需重新输入。编辑保存时校验原资料版本，发现资料已被修改或删除则提示重新加载，不覆盖更新后的内容。

## AI 请求与返回协议

共享模块实现资料模型、草稿编解码和编辑差异计算，便于代码级测试。

- AI 输入只包含固定整理指令、本次输入、可选的当前编辑草稿、允许的分类 ID/名称和必要的字段名参考；不附带聊天历史、记忆、工具或其他资料的内容。
- 要求返回严格 JSON：`records` 数组，每条含 `title`、`categoryId`、`body`、`fields`；`fields` 是有序的 `{name, value}` 数组，名称和值为字符串。限制最多 20 条、每条最多 50 个字段、返回文本最多 100,000 字；拒绝未知分类 ID、重复/空字段名、无有效条目或不符合结构的响应。
- 单条资料编辑必须只返回一条资料；忽略模型返回的 ID/时间元数据，在本地保留原 ID/创建时间。
- 提示词明确区分新增和编辑：字段名允许 AI 归纳，字段值和正文中的事实必须来自用户输入或当前资料。自然语言中的纠正优先于旧信息，不依据常识补出金额、账号、用途等事实。
- 结构校验不能证明事实准确性，保存前仍需用户检查；校验失败不保存，不静默接受部分结果。

## 从待办导入与再次同步

- 生活档案列表提供「从待办导入」。读取当前本地待办内容、状态、重复规则及提醒日期，按最多 20 条且总文本不超过 20,000 字分批交给 AI，识别域名续费、订阅扣款等资料；不只靠关键词过滤。不同批次独立产生草稿，失败批次可重试，已确认的草稿不受影响。
- 展示识别出的资料、原待办引用及字段，用户选择后保存。原待办的提醒、重复规则和完成状态保持原样；导入不删除、完成或禁用待办。
- 每条导入草稿绑定一个真实的 `sourceReminderId`，记录 `sourceReminderVersion`；AI 只能引用本批次待办 ID，同一 ID 只能生成一条资料。禁止编造来源或把待办的提醒时间自动视为订阅到期/扣费时间。
- 重复导入同一个待办时，找到其已有资料生成更新草稿，不新增重复资料。参考已有资料保留用户手动维护的内容，只在用户确认后更新；没有内容变化则跳过。首次导入、更新及取消都不能修改原待办。
- 同步是用户主动发起的单向导入，不后台上传待办。扫描期间的待办修改通过版本校验拦截，提醒用户重新分析；保存资料时同时校验档案版本，避免覆盖后续编辑。
- 新增/编辑时的 AI 格式解析需兼容模型常见的 JSON 代码块包装，同时保留字段、类型、来源、重复项等严格校验；纯说明文字、截断 JSON 和含义不明确的多个结果不能当作成功。

## AI 边界与错误处理

复用默认 AI 配置、已有网络协议和 DI 模式，新增独立的生活档案整理服务，不接入 MCP Agent 或 MemoryExtractService。

现有 `AiService` 会记录异常，错误响应正文可能随异常进入诊断。实现时应沿用底层协议，但为本功能提供不记录请求/响应正文及远端错误正文的调用边界；仅保留固定错误类别、HTTP 状态等非内容诊断，不扩大修改其他 AI 功能。取消脱敏不改变日志内容隔离要求。

仅在用户点击 AI 动作后发送原文/当前编辑草稿和说明；不后台自动整理、不因失败自动调用其他模型。错误信息使用固定中文提示，禁止回显远端异常正文。收到取消必须继续传播取消异常。没有有效 AI 配置时指向配置页面，保留本次输入于当前页面内存。资料最终存储在本地不代表 AI 处理也发生在本地，界面不得声称内容从未外传。

## 本地存储与隔离

为避免现有数据库、记忆重建和数据库备份携带档案，第一版使用独立的 Android 私有文件仓库，位于 `noBackupFilesDir/life_archive/`，不修改 `DailySatori.sq`，不新增数据库迁移。

- 复用 `SecretValueCipher` / Android Keystore AES-GCM；分类清单和全部资料保存为一个完整加密 JSON 快照，标题、分类、属性和正文均不以明文落盘。文件名不包含资料内容；分类删除及资料迁移在同一个快照中原子提交。
- 现有 `SecretCipher.decrypt` 失败时会返回密文，仓库需检查返回值确实是可解析且 ID 匹配的资料；失败必须报错，不展示空列表冒充成功，不覆盖原文件。
- 写入使用同目录加密临时文件和原子替换；串行执行写入/删除，状态更新只发生在成功落盘后。列表搜索在解密后的内存数据中执行。
- Android 实现注入共享仓库接口；Koin 注入 ViewModel，不在 Composable 中访问文件。只支持当前 Android 产品，不为其他平台增加假实现。
- 不纳入现有备份目录收集、数据库导出、全文检索、记忆提取、聊天上下文或任务中心内容。现有 Manifest 已关闭 Android 自动备份。
- 本次不触碰用户正在修改的 `Config.kt`、`BackupService.kt` 及其测试。

**第一版取舍：档案不支持迁移到新设备；卸载/清除数据、Keystore 密钥丢失均可能使档案无法恢复。** 页面需在首次保存前清晰显示此限制，不把仅存在本机的数据描述为已备份。加密导出/恢复属于后续单独设计，不默认为现有备份可以恢复档案。

## 拟修改位置

- `shared/.../service/lifearchive/`：数据模型、动态字段、编辑差异计算、严格响应解析、专用 AI 整理边界及仓库接口。
- `app/.../core/lifearchive/`：加密文件仓库。
- `app/.../ui/feature/lifearchive/`：列表/编辑流程与 ViewModel。
- 现有 `MySpaceScreen`、`HomeScreen`、导航 Routes/NavHost、Koin 模块及中英文字符串：接入入口与页面，复用主题样式。
- `docs/03-app-features.md`：实现后补充功能及私有边界说明。

## 验证与验收

先写最小聚焦测试并确认失败，再实现并运行同一测试。聚焦覆盖：动态字段及自定义分类的解析、严格 JSON、未知分类/重复字段/空或超限响应、编辑只接受一条资料、本地 ID/创建时间保留、编辑差异展示、取消恢复原草稿、迟到响应丢弃、保存冲突不覆盖原资料、分类重命名与删除迁移。

使用假传输捕获实际请求，断言新增只包含本次文字及分类/字段参考，编辑包含当前草稿和补充说明，不携带其他资料值或聊天记忆。使用假加密/文件存储验证落盘不含明文、写入失败保留原档案、损坏/密钥丢失不覆盖数据；Android 编译确认 Keystore 和私有目录接入。

功能结束时合并一次运行受影响模块代码级测试、`:app:compileDebugKotlin` 与 `:app:assembleDebug`（涉及字符串资源），不启动模拟器、不执行 UI 测试、不实际上传用户资料。

当前方案会将本次输入和当前编辑资料直接发送给所选云端 AI，已取消防止这些内容上传的脱敏机制。真实云端模型效果、事实准确性、设备存储行为和 UI 操作仍需后续专项验证，不以代码级测试声称已完成真机验证。
