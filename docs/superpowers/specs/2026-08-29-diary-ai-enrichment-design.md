# 日记 AI 补充与链接内容提取设计

## 目标

在日记编辑器中提供统一的“AI 补充”能力：用户可选中历史事件、人物或知识片段，让 AI 联网查证并补充背景；粘贴普通文章或抖音分享链接后，可在用户确认时提取核心内容。所有结果先预览，只有用户明确确认后才写入当前编辑内容。

## 产品原则

- 粘贴和打开日记编辑器不会自动产生网络、AI 或第三方 API 请求。
- 默认只发送选中文字、有限相邻上下文和用户确认处理的链接，不发送整篇日记。
- AI 结果不得直接覆盖正文或写入数据库，必须先经过预览确认。
- 联网内容应保留 1–3 个 Markdown 来源链接，并标注是否经过联网查证。
- 抖音解析只使用无需登录即可访问的公开分享页面，不调用私有签名接口、不绕过登录，也不默认下载视频。

## 用户交互

### 选中文字补充知识

1. 用户在日记编辑器中选中文字。
2. 点击工具栏中的“AI 补充”。
3. 编辑器显示“正在查证相关背景”，同时保存正文版本、选区位置和选中文字快照。
4. 服务优先联网检索并生成简洁补充；联网失败时提示用户是否使用模型知识继续。
5. 结果在预览面板中展示，正文可继续编辑，并附来源及查证状态。
6. 用户选择“插入到原文后”“替换原文”或“取消”。写入后进入现有撤销栈。

### 粘贴链接提取内容

1. 编辑器检测到新粘贴的 HTTP/HTTPS URL 后，在下方显示“检测到链接 · 提取核心内容”提示条。
2. 检测本身只做本地字符串解析，不发起请求。
3. 用户点击提示条后才解析链接；也可以直接选中链接并点击“AI 补充”。
4. 普通网页显示“正在提取链接内容”；抖音链接显示相同状态但使用抖音适配器。
5. 结果进入统一预览面板，并始终保留原始链接作为来源。

### 预览与冲突保护

预览面板包含可编辑结果、来源、提取完整度、警告以及插入/替换/取消操作。任务执行期间允许继续编辑日记。若完成时正文或原选区已改变，“替换原文”禁用；用户仍可将结果插入当前光标。关闭编辑器或取消任务会取消对应网页加载、搜索和 AI 请求。

## 架构

### DiaryAssistantService

统一接收选区文本、有限相邻上下文、可选 URL 和任务取消信号。它负责识别任务类型、编排提取与生成流程，并返回统一结果：

- `content`：供用户预览和编辑的 Markdown 正文。
- `sources`：最多三个标题与 URL。
- `verificationStatus`：联网查证、仅模型知识或页面直接提取。
- `extractionStatus`：完整正文、公开元数据、无字幕降级等。
- `warnings`：登录墙、字幕缺失或内容截断等非致命提示。

### DiaryKnowledgeEnricher

复用项目现有联网搜索能力获取与选区相关的材料，再调用当前启用的 AI 配置生成简洁背景。提示词要求模型只依据检索材料陈述可核查事实，并输出 1–3 个来源。检索失败时不自动降级，先由用户确认是否使用模型自身知识；降级结果必须标记“未联网查证”。

### DiaryLinkExtractor

普通网页复用现有 `WebpageParserService` 的公开页面加载与正文抽取能力。正文先清洗、限制输入长度，再交给 AI 生成适合日记上下文的核心摘要。正文为空、登录墙或访问失败时不生成推测内容，只返回明确错误和原始链接。

### DouyinLinkExtractor

抖音适配器先解析公开分享短链跳转，再从公开页面读取标题、作者、文案、发布时间、开放图谱字段以及页面中可访问的字幕或文本：

- 有字幕或足够正文时，AI 总结视频核心内容。
- 只有标题和文案时，生成降级摘要并标记“未获取到视频字幕”。
- 页面不可访问或公开信息不足时，停止并返回可重试错误，不下载视频或虚构内容。

适配器使用独立接口与普通网页解析隔离，后续可用相同模式支持其他视频平台，但本期不实现额外平台。

### 编辑器集成

`DiaryEditorSheet` 继续持有 `TextFieldValue` 与撤销/重做栈。新增编辑辅助状态保存任务 ID、正文快照、选区快照、加载状态、预览结果与错误。服务层不直接修改日记仓库；用户确认后，编辑器以一次原子文本操作插入或替换，并压入一次撤销记录。日记仍通过现有保存动作持久化。

## 数据与隐私边界

- 知识补充仅发送选区与固定上限的前后文，用于消歧和语气衔接。
- 链接摘要仅发送抽取后的网页材料，不附带日记其他正文。
- 来源 URL 和生成结果只在用户确认插入后成为日记内容。
- 本期不新增永久链接缓存；仅在当前编辑会话内按规范化 URL 缓存成功结果，避免重复点击产生费用。
- 日志不得记录日记正文、网页全文、AI 提示词或用户凭据。

## 成本与并发控制

- URL 检测完全本地执行，用户确认前零请求。
- 同一编辑会话内，相同规范化 URL 复用成功结果。
- 同一时刻只允许一个日记辅助任务；新任务必须先取消旧任务。
- 网页内容先本地清洗和截断，再调用 AI。
- 工具栏和提示条在任务运行时防重复点击，并提供取消入口。

## 错误处理

- 未配置 AI：提示前往 AI 设置，不修改正文。
- 搜索失败：提供“使用模型知识继续”，不静默降级。
- 网页超时、登录墙、正文为空：保留链接并展示原因，不生成虚构摘要。
- 抖音短链失效或公开信息不足：返回平台特定错误；只有元数据时允许明确标记的降级结果。
- AI 超时、空响应或格式异常：保留任务输入，可重试或取消。
- 正文冲突：禁用替换，只允许插入当前光标。
- 关闭编辑器或取消：协作式取消所有下游工作，迟到结果不得更新已销毁界面。

## 测试范围

- URL 识别、规范化、任务分类和 Markdown 来源格式。
- 普通文字联网补充、搜索失败确认以及模型知识降级标记。
- 普通网页正文提取、登录墙、空正文、截断和摘要。
- 抖音短链跳转、完整元数据、有字幕、无字幕降级和失效链接。
- 选区插入、替换、撤销、正文版本冲突和当前光标插入。
- 重复点击、会话缓存、取消、超时和迟到结果隔离。
- 粘贴链接不会触发网络或 AI 请求。
- 服务输入只包含选区、有限上下文或确认处理的链接，不包含完整日记。

## 本期不包含

- 自动分析整篇日记或后台批量补充历史日记。
- 自动下载、保存或转写抖音视频音轨。
- 绕过平台登录、验证码、访问控制或反爬机制。
- 永久保存网页快照或建立跨日记的链接摘要缓存。
- 支持抖音以外的其他视频平台专用适配器。
